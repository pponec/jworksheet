# jWorkSheet


**jWorkSheet** is an open source personal desktop time tracker for your projects,
data are presented in a spreadsheet like format.
Application offers some completed work sheet reports, however you can create your own user reports by XSL transformations.

### Requirements

A **JDK 17 or newer** is required to run the application - a plain JRE is not enough.
The [Ujorm 3](https://ujorm.org/) framework builds the metamodel of the domain objects
at the run time using the Java compiler, so the `jdk.compiler` module must be available.
